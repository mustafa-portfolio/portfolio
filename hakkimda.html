Hakkımda

Kod yazmayı, kod yazarak öğreniyorum.

Ankara'da yaşıyorum ve front-end geliştirmeye kendi kendime, gerçek projeler kurarak öğreniyorum. Bir konuyu okumak yerine önce denemeyi, hatalarımdan öğrenmeyi tercih ediyorum — bu site de tam olarak o şekilde ortaya çıktı.

Şu anda odağım temiz, erişilebilir HTML/CSS yazmak ve JavaScript ile arayüzleri gerçekten etkileşimli hale getirmek. Sıradaki hedefim bir framework öğrenmek ve API'lerle daha karmaşık uygulamalar kurmak.

Bu portfolyo statik bir CV değil — büyüdükçe güncellediğim, canlı bir günlük gibi düşünülebilir.

  • HTML5 Rahat kullanıyorum
  • CSS3 / Flexbox & Grid Rahat kullanıyorum
  • JavaScript (DOM, olaylar) Geliştiriyorum
  • Fetch API & JSON Geliştiriyorum
  • Git & GitHub Öğreniyorum
  • Responsive tasarım Rahat kullanıyorum
